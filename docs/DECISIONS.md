| D-032 | 2026-11-16 | **Kummies are taken back when an order is cancelled or refunded.** The order is re-counted without the refunded goods (full refund → all points; partial → the difference, or all if the rest drops below €30). Points come from that order's own lot first, then from the customer's other valid points (soonest-expiring first); the balance never goes negative — any shortfall is reported to the refund flow (M2), which decides whether to deduct it. | Decided (owner) |
| D-031 | 2026-11-16 | **Kummies validity and reminders.** Points are recorded on the day the order is paid (Bulgarian date) and their validity is counted from that day; spending uses the points that expire first. The customer gets **3 reminders — 14, 3 and 1 day before expiry** — by e-mail and, if allowed in the app, as a push, only while unused points remain. Validity: **6 calendar months** from the payment day (paid 16 Nov → usable through 16 May; month-end dates move to the last day of the shorter month). Channels: **e-mail always** (a service message of the Club programme, stated in the Club terms); **app push only with the "Club drops" opt-in** (its label now says it includes Kummies reminders); quiet hours 22:00–08:00 apply to both. | Decided (owner) |
