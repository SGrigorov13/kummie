02 · Colour

Five colours, fixed jobs

Electric Violet is the brand ground. Glow is the single call-to-action colour. Hot Pink is reserved for LIMITED — scarcity only, never decoration. Spotlight is for editorial and OFFICIAL. Ink replaces black everywhere.

Electric Violet
#5B14E5 · rgb(91,20,229)
Primary ground, header, app chrome, packaging. White or Glow text only.
Glow
#B4FF3A · rgb(180,255,58)

08 · Instructions for web developers

Build spec — website

Design tokens — ship these as CSS custom properties
--kum-violet: #5B14E5; /* brand ground */ --kum-ink: #2D0075; /* all text, no black */ --kum-glow: #B4FF3A; /* primary action */ --kum-pink: #FF2E9A; /* LIMITED only */ --kum-spotlight:#FFE44D; /* OFFICIAL, editorial */ --kum-paper: #F4F2EF; /* page background */ --kum-white: #FFFFFF; --kum-font-display: "Archivo Black", system-ui, sans-serif; --kum-font-text: "Space Grotesk", system-ui, sans-serif; --kum-font-mono: "Space Mono", ui-monospace, monospace; --kum-radius-sm: 8px; --kum-radius-md: 14px; --kum-radius-lg: 22px; --kum-radius-pill: 999px; --kum-space: 4px; /* all spacing = multiples of 4 */ --kum-shadow: 0 18px 46px -24px rgba(45,0,117,.28);
Structure
  • Responsive-first, PWA-capable. No native app in stage 1.
  • Top-level nav: Shop · Collect · Magazine · Teen · Club. Search is always visible.
  • Breakpoints 360 / 768 / 1024 / 1440. Content max-width 1120 px.
  • 12-column grid desktop, 4-column mobile, 24 px gutters.
  • Promo bar is a dismissible region, not a fixed overlay.
  • Every product page renders: version, official/original classification, dispatch estimate, delivery region, manufacturer / responsible-person block, safety information, return exceptions.
Components
  • Buttons: pill, Glow with Ink text for primary; outlined Ink for secondary; never pink.
  • Badges are a single component with a fixed enum — no free-text badges.
  • Product card: 3:4 image, title 2 lines max, one sourcing badge, price, one state badge.
  • Star monogram is an inline SVG sprite, one file, currentColor-aware.
  • Equaliser is a CSS-animated component, paused by default, animating only on hover/active.
  • Forms: 44 px minimum touch height, labels above fields, errors in Ink with an icon, never colour alone.
Accessibility & performance
  • WCAG 2.2 AA: 4.5:1 for text under 24 px. Use the approved pairs in section 02 only.
  • Visible focus ring: 3 px Glow on violet, 3 px Violet on Paper.
  • Respect prefers-reduced-motion — equaliser and star animations stop.
  • Self-host the three fonts, woff2, font-display: swap, subset Latin + Cyrillic.
  • Images: AVIF/WebP, lazy below the fold, explicit width and height.
  • Targets: LCP under 2.5 s on 4G, CLS under 0.1.
  • Full Bulgarian and English localisation from day one; EUR and BGN display.
Non-negotiable
  • Total price, shipping and delivery window visible before checkout — no surprise customs.
  • Cookie consent before any non-essential script; analytics loaded after consent.
  • Withdrawal, returns, guarantee and complaint pages linked from every footer.
  • Teen section has no comments, no DMs, no user profiles, no location data.
  • No artist imagery in templates or placeholders.
  • Hot Pink is wired to one boolean: product.isLimited.
09 · Instructions for mobile app developers

Build spec — app

The app is a retention tool, not a mobile copy of the shop. It ships only after the web business proves repeat purchase. Its job: comeback notifications, collection, wishlist, drops, Ask KUMMIE.

Icon & launch
K
  • Icon: violet ground, pink star at −20°, white K. Adaptive icon keeps the star inside the 66% safe circle; the K is dropped on the round mask.
  • Splash: violet, stacked lockup centred, equaliser bars animate once (600 ms) then hand off.
  • App name on store: “KUMMIE — K-pop Shop & Collect”. Subtitle: “Your K-pop Chingu”.
Navigation & layout
  • Five tabs: Home · Shop · Collection · Drops · Chingu (Ask KUMMIE).
  • Tab bar: Paper in light mode, Ink in dark mode; active icon Violet on light, Glow on dark.
  • Minimum touch target 44×44 pt / 48×48 dp. Base spacing 4 pt.
  • Dark mode is first-class: Ink background, Paper text, Glow actions.
  • Type scale mirrors web and must honour OS dynamic type up to 200%.
  • Native components on each platform — no cross-platform imitation of the other OS.
Motion & sound
  • One signature animation: the equaliser. Used for loading, live drops and Ask KUMMIE thinking.
  • Star rotates ±6° maximum on tap. It never spins.
  • Transitions 180–240 ms, ease-out. No bounce, no parallax.
  • No sound by default. Optional single tick on drop-countdown only.
  • Honour reduced-motion and reduced-transparency settings.
Notifications
  • Four opt-in categories, separately toggleable: comebacks, restocks, order status, Club drops.
  • Copy pattern: “⭐ Stray Kids comeback — pre-orders open 10:00.” Under 60 characters.
  • Order status is transactional and never bundled with marketing.
  • Quiet hours 22:00–08:00 local, no exceptions for drops.
  • Maximum two marketing pushes per week per user.
Data, age & compliance
  • Collection and wishlist data sync through the same API as web — one customer record.
  • Age gate at signup; minors get no personalised advertising and no public profile.
  • No third-party ad SDKs in v1. Analytics is consented, aggregated and documented.
  • Store listing declares data use truthfully; screenshots use original KUMMIE product photography only.
  • Ask KUMMIE answers are labelled as recommendations and must not invent stock or release dates.
Handover checklist
  • Logo package: SVG (horizontal, stacked, monogram, one-colour), PNG @1x/@2x/@3x, ICO favicon set.
  • Icon set: 24 px SVG sprite, Ink and white.
  • Token file: CSS custom properties, iOS colour set, Android colors.xml.
  • Font licences: self-hosted woff2 plus the original OFL files.
  • Badge enum with copy in English and Bulgarian.
  • Social export templates: 1:1, 4:5, 9:16.
Wordmark and lockups here use Archivo Black and Space Grotesk (SIL Open Font License) as production-ready stand-ins. Before trademark filing, the K and the wordmark should be redrawn as custom outlines so the mark is ownable. All shapes are original geometry with no third-party IP.
